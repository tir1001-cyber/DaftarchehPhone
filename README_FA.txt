دفترچه تلفن شخصی - پروژه اندروید
================================

این پروژه برای Android 13 به بالا (minSdk=33) ساخته شده است.

ویژگی‌ها:
- افزودن، جستجو، ویرایش و حذف مخاطب
- ذخیره آفلاین در فایل خصوصی contacts.json داخل فضای داخلی برنامه
- خروجی JSON با انتخاب محل ذخیره
- وارد کردن JSON و ادغام بر اساس شماره تلفن
- بدون مجوز اینترنت و بدون سرور

ساخت APK با گوشی:
1) در GitHub یک حساب بسازید یا وارد شوید.
2) یک Repository جدید و خالی بسازید.
3) فایل ZIP پروژه را در گوشی استخراج کنید.
4) همه محتویات پوشه پروژه را در Repository آپلود کنید؛ پوشه .github نیز باید آپلود شود.
5) در تب Actions، گزینه "Build Android APK" را انتخاب کنید.
6) روی Run workflow بزنید و منتظر سبز شدن اجرای کار بمانید.
7) وارد اجرای موفق شوید و از بخش Artifacts فایل phonebook-debug-apk را دانلود کنید.
8) ZIP دانلودشده را باز کنید و app-debug.apk را نصب کنید.

نکته: برای ساخت APK از GitHub Actions اینترنت لازم است. خود اپلیکیشن پس از نصب، آفلاین کار می‌کند.
فایل contacts.json داخلی برنامه با حذف برنامه پاک می‌شود؛ بنابراین مرتب Export بگیرید.
Import با شماره تلفن ادغام می‌کند و در صورت وجود شماره، نام آن را به‌روزرسانی می‌کند.

این نسخه آزمایشی است و پیش از نگهداری اطلاعات مهم، حتماً Import/Export را با چند مخاطب تست کنید.
